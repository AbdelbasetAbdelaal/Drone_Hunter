# Drone Hunter — Processed CC0 Audio Assets

Source pack: Kenney Sci-Fi Sounds.
License: CC0 (see License.txt).

These files were selected from the supplied Kenney pack, trimmed where appropriate,
converted to 44.1 kHz stereo OGG Vorbis, and loudness-normalized for consistent gameplay.

IMPORTANT LIMITATION:
The supplied pack does NOT contain dedicated mission-success or mission-failure music,
nor dedicated missile/rail/tesla recordings. The mappings in this folder are practical
base layers from the pack, not claims that every sound is a perfect real-world recording.
For mission music, obtain a separate CC0 music source before release.
