# Drone Hunter 2D

Fast-paced 2D sci-fi tactical arcade space shooter.

## Specifications
- **Engine**: Godot 4.3
- **Renderer**: GL Compatibility
- **Platform**: Windows Desktop
- **Resolution**: 1280x720 (2D)

## Features
- **25 Missions**: 5 sectors of escalating tactical combat.
- **5 Drone Classes**: Striker, Interceptor, Assault, Arc, Command.
- **11 Weapons**: Pulse Cannon, Rapid Autocannon, Scatter Shotgun, Homing Missiles, Missile Barrage, Heavy Plasma Orb, Railgun Accelerator, Plasma Laser Beam, Arc Lightning Tesla, Cluster Torpedo, EMP Shockwave.
- **Abilities**: Roll, EMP, Cloak, Overdrive, Overclock.

*Note: Boss systems and Drone skins are excluded from this release.*

## How to run from source
1. Open Godot 4.3.
2. Import the project using project.godot.
3. Press Play (F5).

## How to run the Windows release build
1. Execute export_release.bat to create the build in the elease/ directory.
2. Run elease/DroneHunter.exe.
